# Repository guidance

This repository converges a personal development environment across supported
macOS and Ubuntu hosts. Preserve the public command interface and the safety
properties documented in `README.md`.

## Agent skills

Issues and PRDs live in this repository's GitHub Issues. See
`docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the standard five-role label vocabulary. See
`docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Read `CONTEXT.md` and relevant decisions
under `docs/adr/`; see `docs/agents/domain.md`.
