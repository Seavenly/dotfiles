# Domain docs

This is a single-context repository.

Before changing repository behavior, read:

- `CONTEXT.md` for the repository's domain language;
- relevant decisions under `docs/adr/`;
- `README.md` for the supported public behavior.

Use glossary terms consistently. If a change introduces a durable domain
concept, add it to `CONTEXT.md`. Surface conflicts with an existing ADR rather
than silently overriding the decision.
