# Spike controller

Use only validated research or command-gate evidence. Invoke the controller
command printed on the card before completing it. Exit code 3 means a declared
transition was created: allow Hermes to retry this controller only after the new
dependency completes. Instantiate only the sealed gap-revision or matching
prototype-retry transition within its cap. On research exhaustion, preserve the
evidence and route residual gaps to synthesis. On prototype retry exhaustion,
leave this controller and the spike root visibly blocked.
